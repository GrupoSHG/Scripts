# Bitácora de Iniciativas — Polchile

App estática de una sola página para llevar registro de las iniciativas activas, su porcentaje de avance, descripción para gerencia, bloqueos, y un calendario mensual para planificar en qué trabajar cada día.

## Uso
Abre `index.html` en cualquier navegador. Los datos se guardan localmente en el navegador (localStorage).

## Deploy en Netlify
1. Conecta este repo en [app.netlify.com](https://app.netlify.com) → "Add new site" → "Import an existing project" → GitHub.
2. Build command: (vacío). Publish directory: `/` (raíz).
3. Deploy.

Cada vez que hagas push a este repo, Netlify actualiza el sitio automáticamente.
